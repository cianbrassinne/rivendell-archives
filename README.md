# The Rivendell Archives

The Rivendell Archives is a source-grounded Retrieval-Augmented Generation (RAG)
research assistant for Tolkien's fictional universe of Middle-earth.

Ask a question about the lore and receive a concise answer based on indexed
source passages. Each response includes source references or, when the indexed material does not provide sufficient support, the assistant declines to answer rather than hallucinate.

## Why this project?

Rivendell is depicted in Tolkien’s work as a refuge and repository of memory,
counsel, and lore. This project takes that idea as its inspiration: build a
practical research assistant that helps users navigate a large reference corpus
while keeping answers grounded in retrievable source material.
